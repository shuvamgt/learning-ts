# Workspace instructions

- This is a TypeScript learning workspace. Treat examples and exercises as learner-owned work.
- Do not proactively autocomplete partial code, fill in exercise answers, implement inferred TODOs, or make unsolicited edits. Only complete or change code when the user explicitly asks.
- Preserve intentional type errors and incomplete examples unless the user asks to fix or complete them.
- When a request is ambiguous about whether code should be completed, ask before editing.

These instructions guide Copilot chat and agent behavior; they do not disable VS Code IntelliSense or inline suggestions.
